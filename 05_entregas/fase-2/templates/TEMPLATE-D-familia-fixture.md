# TEMPLATE-D — Resolução da família do modelo Poliureia/geotecnia (BLK-4)

- **Responsável pelo preenchimento:** Comercial + Engenharia
- **Quando usar:** ao resolver a divergência de família dos modelos de proposta aprovados
- **Contexto (achado preservado em T1.15):** os dois modelos aprovados reportam `family=geotecnia`, inclusive o registro nomeado Poliureia — sem alteração automática

## Preenchimento

| Campo | Valor |
|---|---|
| Decisão (resolver registro / excluir modelo / manter como está justificado) | ⬜ |
| Justificativa ≥10 caracteres | ⬜ |
| Nova família do registro Poliureia (se resolvido) | ⬜ |
| Fixture de domínio associada (arquivo assinado) | ⬜ |
| Responsáveis (Comercial + Engenharia) e data | ⬜ |

## Prova de aceitação

- Decisão registrada com justificativa e responsáveis — sem edição silenciosa.
- Se mantido como está, justificativa explícita do porquê.
- Fixture assinada pelo responsável com entradas, unidades, coeficientes, fórmula, resultados, tolerância, precisão/arredondamento e versão esperados (SPEC-2-001/2-002).
